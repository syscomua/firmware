# Танграм: автоматическая сборка фигур из 7 долей

`tangram.py` — скрипт на чистом Python 3, без зависимостей. Результат сохраняет в SVG
(открывается в любом браузере).

## Доли

Квадрат со стороной 4, 7 долей (цвета как на фото):

| Имя | Доля | Площадь |
|-----|------|---------|
| L1, L2 | большие треугольники | 4 + 4 |
| M  | средний треугольник  | 2 |
| SQ | квадрат              | 2 |
| P  | параллелограмм       | 2 |
| S1, S2 | маленькие треугольники | 1 + 1 |

## Методика (как не придумывать фигуры вручную)

1. **Сетка.** Каждая клетка 1×1 разрезана обеими диагоналями на 4 треугольника.
   Стороны всех долей идут по линиям сетки или по диагоналям, поэтому каждая доля —
   это просто набор таких треугольников (всего 64). Повороты на 90° и зеркальные
   отражения переводят этот набор в другой набор на той же сетке.
2. **Сборка заданного силуэта = точное покрытие.** Каждый треугольник силуэта
   должен быть закрыт ровно одной долей, и каждая доля использована ровно один раз.
   Это задача exact cover; её решает алгоритм X Кнута (`solve`).
3. **Новые фигуры = случайный рост.** Доли по одной прикладываются к уже
   выложенным так, чтобы касаться по стороне и не перекрываться (`random`). Режим
   `compact` предпочитает положения с большим числом общих сторон. Повторы
   с точностью до поворота отбрасываются. Силуэт такой фигуры — готовая
   головоломка, а ответ к ней уже есть (`--puzzle`).
4. **Все фигуры класса = перебор силуэтов + решатель.** `convex` перебирает все
   выпуклые многоугольники площади 16 и находит ровно 13 собираемых. Это совпадает
   с известной теоремой Ванга–Сюна (1942) и подтверждает, что модель верна.

Ограничение: доли поворачиваются только на углы, кратные 90° (и переворачиваются).
Поворот одной доли на 45° уводит её с сетки, такие фигуры модель не находит.

## Использование

```sh
python3 tangram.py pieces                         # разбивка квадрата на доли -> out/pieces.svg
python3 tangram.py targets                        # встроенные силуэты
python3 tangram.py --labels solve square          # единственное решение квадрата
python3 tangram.py solve all --max 0              # все решения всех встроенных фигур
python3 tangram.py solve --poly "0,0 8,0 4,4"     # свой силуэт (вершины в целых координатах)
python3 tangram.py --labels convex                # все 13 выпуклых фигур
python3 tangram.py random -n 24 --seed 7          # 24 новые фигуры
python3 tangram.py random -n 12 --puzzle          # силуэт-задача + ответ
python3 tangram.py random -n 8 --symmetric --no-holes --puzzle
```

Общие флаги: `--out DIR` (по умолчанию `out/`), `--no-flip` (не переворачивать доли),
`--labels` (подписать доли), `--cols N` (колонок в галерее).

## Фигуры с листка «Розвиваюча гра «Танграм»» (папка `sheet/`)

Здесь доли можно поворачивать на 45°: движок `tg45.py` (детали, решатель силуэтов
с поворотами на 45°). Готовые 48 фигур лежат в `sheet/figures.json`, страница с
пошаговыми инструкциями — `sheet/tangram.html`.

Как получены фигуры:
- `sheet/auto.py`, `sheet/auto2.py` — силуэт снимается с фото, стороны приводятся
  к размерам деталей, решатель находит раскладку;
- `sheet/fuzzy.py` — детали раскладываются прямо по контуру с фото и «примагничиваются»
  друг к другу;
- `sheet/templates.py` — шаблоны силуэтов с параметрами, подбор по похожести на фото;
- `sheet/manual.py` — фигуры, разложенные вручную (помечены как «упрощена»).

Сборка страницы: `python3 sheet/build.py html sheet/tangram.html`
(тексты шагов генерирует `sheet/instructions.py`, шаблон — `sheet/template.html`).
Для скриптов, работающих с фото, нужны `shapely`, `opencv-python-headless`, `Pillow`.

### Сдвиг деталей и исправленные силуэты
- На листке детали часто приложены со сдвигом вдоль общей стороны, а не уголок к уголку.
  `sheet/sa.py` подгоняет 7 деталей к маске с фото методом отжига (положения непрерывные,
  повороты кратно 45°), затем «примагничивает» соседние стороны и проверяет, что нет наложений.
- Маски с фото: освещение выравнивается (`flatten` в `trace.py`), поэтому тень руки и блики
  меньше портят силуэт; отдельные пятна вдали от фигуры отбрасываются.
- Ручные исправления и результаты подгонки лежат в `sheet/fixes.json` и имеют приоритет
  при `build.py merge`.

### Печатные материалы
```sh
python3 sheet/print.py out/print --side-cm 12      # сторона собранного квадрата вашего набора
python3 sheet/print.py out/print --lines           # задания с линиями (облегчённый вариант)
```
Получаются `zadaniya.pdf` (силуэт 1:1 на листе), `otvety.pdf` (схема с номерами шагов и текст),
`detali.pdf` (детали для вырезания и контрольный квадрат), `karta_a2.pdf` (все 48 схем на плакате A2)
и `karta_a4.pdf` (те же схемы на двух листах A4). Печатать в масштабе 100%.

Усе одним архівом (папки «Підготовка / Завдання / Складання / Карта / Картки»):
```sh
python3 sheet/print.py out --pack --side-cm 12   # -> out/Танграм_матеріали/ і out/Танграм_матеріали.zip
```
Готовий архів лежить поруч: `tools/tangram/Танграм_матеріали.zip`.

Книга (усе в одному PDF з розділами і покажчиком): `python3 sheet/book.py Танграм_книга.pdf --side-cm 12`.
